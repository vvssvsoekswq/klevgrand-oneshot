## Overview

Klevgrand OneShot is a minimal drag-and-drop sampler for single-shot sounds — drums, foley, stabs — with pitch, reverse, fade, and envelope controls that keep the workflow fast and distraction-free.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Klevgrand OneShot** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Drag and Drop** | Drop any WAV or AIFF directly onto the instrument for instant use |
| **Pitch Control** | Semitone and fine-tune transposition with keyboard mapping |
| **Reverse Mode** | Play samples backwards with adjustable pre-roll fade |
| **Fade Envelope** | Attack and release fade curves for smooth sample integration |
